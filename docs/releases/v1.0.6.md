# v1.0.6

Released September 12, 2026.

## Planning workflow

- Importing a plan while viewing a demo now exits demo mode and imports directly into the personal workspace. Import progress, success and failure remain visible in App Config.
- Overview now shows the after-tax spending goal, estimated sustainable spending capacity, and switchable Projection, Net worth, Cash flow and tax, and Contributions graphs.
- Market risk remains under Plan optimizer through **Check current status**, alongside the difficult-market and Monte Carlo checks.
- Action plan and Withdrawal strategy are consolidated in **Plan optimizer**. A single goal selector starts spending, end-of-plan net-worth, lifetime-tax, retirement-date, or risk/funding work; specific tools remain available for review.

## Rental comparisons

- Quick comparison now speeds up long single-rental searches with a 30-option coarse-to-fine search and full-precision verification of finalists. Thorough comparison still checks every available sale year.
- **Use this sale and CCA setting** now saves the selected result immediately and reports save failures in place.

## Validation

- Added engine coverage for bounded single-rental Quick searches.
- Added browser coverage for importing from demo mode, persistent import status, Overview metrics and graph tabs, hidden Overview risk, and the consolidated Plan optimizer.

## Upgrade

- **Docker/Unraid:** update to `ghcr.io/asmegin/retirement-calculator:1.0.6`, keep the existing `/app/data` mapping, and recreate the container.
- **Compose:** set `APP_VERSION=1.0.6`, then run `docker compose pull` and `docker compose up -d --no-build`.
- **Standalone:** download `retirement-calculator-standalone.zip` from the v1.0.6 release and replace the old application files. Export a plan backup before upgrading.
