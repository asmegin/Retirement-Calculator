# Canadian Retirement Calculator 1.01

Version **1.0.1** (`v1.0.1`), displayed as **1.01**. This update adds public/static hosting, privacy tools and a simpler first-run experience while retaining Docker/Unraid and fully offline installations.

## Changes since 1.0.0

- **GitHub Pages support:** the complete calculator runs as a static website, including under a project subpath. Static mode makes no API or Socket.IO requests. Docker keeps its REST persistence and live synchronization, with HTTP refresh when WebSockets are unavailable.
- **Safer storage:** project-specific browser storage, migration from older localStorage/IndexedDB plans, serialized server writes, atomic file replacement and up to 30 configuration snapshots. Server interruptions report unconfirmed saves rather than switching to a different storage destination.
- **Password-encrypted backups:** Export Plan offers optional AES-256-GCM encryption with a password-derived key, fresh salt and IV. Import Plan automatically detects encrypted files and requests the password. Plain exports use a versioned JSON envelope; existing raw JSON exports still import.
- **Discreet display:** an eye toggle masks displayed amounts, balances, table figures and charts, with a locally saved preference.
- **Simpler setup:** a three-step wizard covers household ages/province/retirement targets, income and monthly or annual spending, then core account balances. Every step offers Skip to Dashboard. New plans use neutral placeholders instead of embedded household data.
- **Isolated demo profiles:** explore a fictional Canadian couple or an incorporated business owner with a rental, corporate investments and CCA. A clear badge identifies demo mode. Demo edits stay in a separate browser workspace, even on Docker; Start My Own Plan returns to the personal plan or fresh setup.
- **iOS home-screen support:** Apple standalone metadata, touch icons and a web manifest allow a home-screen launch without browser chrome. A hosted site still needs connectivity to load its files; the extracted ZIP remains the offline option.
- **Deployment improvements:** locked dependencies, a non-root container, health checks, hardened Compose settings, and CI checks that gate multi-architecture `linux/amd64` / `linux/arm64` image builds and Pages deployment.
- **Security hardening:** reject unsafe object keys, oversized structures and excessive planning horizons; restrict backup restore filenames; prevent imported labels from becoming active HTML; and keep internal paths and stack details out of API error responses.

The Canadian calculation features from 1.0.0 remain available: withdrawal-order and annual strategy comparisons, rental sale/CCA analysis, earlier retirement searches, tax-saving comparisons, scenarios, pensions, estate settings and market checks.

## Install and upgrade

- **Standalone:** download `retirement-calculator-standalone.zip`, extract every file, then open `index.html` in a recent desktop Edge or Chrome browser. Verify the download against `SHA256SUMS.txt`.
- **Docker/Unraid:** use `ghcr.io/asmegin/retirement-calculator:1.0.1` after the release tag build succeeds. Keep port `3333` and the `/app/data` volume mapping. While reviewing this draft, build the `release/1.0.1` source branch locally instead of pulling an unpublished image.
- **GitHub Pages:** select GitHub Actions as the repository's Pages source. The updated main/master workflow deploys the public client after checks pass. To preview locally, run `node scripts/build-static.js` and serve `dist/pages` with a static web server.

Export your plan and back up server appdata before updating. Existing plans are retained; legacy browser records are copied on first save without deleting the originals. Review balances and settings after migration. Scenario collections are separate from the main plan export.

**Unraid permissions:** the new container defaults to UID/GID `1000:1000`. Ensure the mapped appdata directory and existing files are writable by the container user. For Unraid appdata owned by `99:100`, use `APP_UID=99` / `APP_GID=100` in Compose or `--user 99:100` in the container's Extra Parameters.

**Backup compatibility:** older versions may not understand the new versioned or encrypted export format. Keep a pre-upgrade export if rollback is needed. Passwords cannot be recovered. Encryption requires Web Crypto through HTTPS, localhost or a supported offline browser; plain HTTP on a LAN may not provide it. Privacy masking does not encrypt browser/server storage, automatic snapshots or unencrypted exports.

The [installation guide](https://github.com/asmegin/Retirement-Calculator/blob/release/1.0.1/README.md), [hybrid deployment notes](https://github.com/asmegin/Retirement-Calculator/blob/release/1.0.1/docs/hybrid-deployment.md) and [security review](https://github.com/asmegin/Retirement-Calculator/blob/release/1.0.1/docs/security-review.md) are also included in the standalone ZIP.

## Verification and limits

65 Node tests pass. Browser suites cover static root/project paths, server and offline operation, onboarding, privacy, encrypted backups and wrong-password recovery, demo isolation, migration, comparisons, persistence and mobile layouts. The dependency audit reports no known vulnerabilities at preparation time.

Docker runtime verification is configured in CI; it was not run locally because Docker is unavailable in the preparation environment. Physical iOS installation and the deployed Unraid/Pages environment have not been certified by these local checks.

This remains a planning calculator, not tax-return software or a guarantee of retirement outcomes. Tax schedules use the documented indexed 2025 base; this release does not introduce a new tax-law update. Consult the calculation notes and review assumptions before acting on projections.
