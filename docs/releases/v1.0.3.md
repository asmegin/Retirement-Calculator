# Canadian Retirement Calculator 1.0.3

The rental sale calculator now answers the retirement question first: **how much more can I spend each month if I sell this property, and when?**

## Changes since 1.0.2

- **Monthly spending comes first.** Every tested sale year and CCA option gets an estimated sustainable after-tax spending amount in today's dollars. The main recommendation shows extra monthly capacity versus current settings, alongside the total supported spending.
- **Sale options ranked by spending.** Current settings remain the first table row; alternatives are sorted by monthly capacity. An option can improve capacity even when the entered spending goal is still too high.
- **Tax and inheritance are supporting details.** Expand the trade-offs section to compare lifetime tax and ending net worth. Lower tax is no longer labelled an overall improvement; it can reflect lower income. These illustrations use the entered spending goal and include terminal tax for both selling and keeping the rental.
- **Clearer review and assumptions.** Review shows ages in the sale year and the spending change, followed by the sale and tax breakdown. Spending estimates retain the plan's lifespan/estate settings, retirement dates and spending schedule. Applying changes the sale/CCA settings and clears the old annual withdrawal schedule; it keeps the spending goal for separate review.
- **Input review prompts.** The comparison highlights an all-building allocation and additional deductible interest alongside a mortgage, so users can check land allocation and possible double-counting. Entered values are never changed automatically.
- **Responsive results.** Cards have proper spacing, tax details start collapsed, and the table works on narrow screens. Longer comparisons report progress and can be cancelled.

No saved-plan migration or tax-law update is included. Estimates depend on entered values and assumed future returns; they are not guarantees or Monte Carlo confidence levels. The search reserves no minimum inheritance and flags its $40,000/month ceiling. Small differences between years may not be meaningful.

## Install or upgrade

- **GitHub Pages:** open the [Canadian Retirement Calculator](https://asmegin.github.io/Retirement-Calculator/) and refresh an existing tab.
- **Standalone:** download `retirement-calculator-standalone.zip` and `SHA256SUMS.txt`, verify the checksum, extract every file, then open `index.html` in Edge or Chrome. Export your plan before changing folders, because offline browser storage can depend on file location.
- **Docker/Unraid:** update to `ghcr.io/asmegin/retirement-calculator:1.0.3` and recreate the container while retaining the `/app/data` mapping and existing host port. With Compose, set `APP_VERSION=1.0.3`, run `docker compose pull`, then `docker compose up -d --no-build`.

Export your plan and back up appdata before upgrading. The mounted data directory and its `backups` subdirectory must remain writable by the configured container user; an image update does not repair host-folder ownership. See the [installation guide](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.3/README.md) and [comparison assumptions](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.3/docs/withdrawal-and-rental-comparisons.md).
