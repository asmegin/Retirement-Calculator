# Canadian Retirement Calculator 1.0.2

This maintenance release fixes the spending-goal card on the retirement overview.

## Changes since 1.0.1

- The **Compare withdrawal options** button now reserves its full height and sits below the monthly spending description. It no longer overlaps the text above or the help text below.
- Button text wraps within the card on narrow screens. Print output continues to hide the button.
- Installation examples and default Docker image settings now use version 1.0.2.

The calculation engine, saved-plan format and Canadian tax assumptions are unchanged.

## Install or upgrade

- **GitHub Pages:** open the [Canadian Retirement Calculator](https://asmegin.github.io/Retirement-Calculator/). Refresh an existing tab to load the updated styles.
- **Standalone:** download `retirement-calculator-standalone.zip` and `SHA256SUMS.txt`, verify the checksum, then extract all files and open `index.html` in Edge or Chrome. Export your plan before moving to a new folder, since browser storage can depend on the file location.
- **Docker/Unraid:** use `ghcr.io/asmegin/retirement-calculator:1.0.2`, retain your `/app/data` volume and port `3333` mapping, and recreate the container. With Compose, set `APP_VERSION=1.0.2`, then run `docker compose pull` and `docker compose up -d --no-build`.

Export your plan and back up appdata before upgrading. No data migration is required from 1.0.1. See the [installation guide](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.2/README.md) for full setup instructions.

## Validation

The spacing fix was checked in Edge at viewport widths of 320, 390, 760, 1024 and 1440 pixels, plus print mode. The release workflow gates publication on the Node tests, static/offline/server browser suites and Docker runtime checks, and verifies the standalone ZIP checksum.
