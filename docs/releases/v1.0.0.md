# Retirement Calculator 1.0

The first numbered release of the Canadian retirement planner, with standalone browser and Docker/Unraid installations.

## Install

- **Standalone:** download `retirement-calculator-standalone.zip` below, extract every file, and open `index.html` in desktop Edge or Chrome. No server or internet connection is needed after download.
- **Docker/Unraid:** use `ghcr.io/asmegin/retirement-calculator:1.0.0`, expose port `3333`, and persist `/app/data`.
- **Source:** Node.js 22+, `npm install`, `npm run build`, then `npm start` from `src` with a writable `DATA_DIR`.

The [README](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.0/README.md) includes complete setup instructions, Compose and Unraid examples, a user guide, backups and troubleshooting. The standalone ZIP also includes the README and supporting documentation. `SHA256SUMS.txt` verifies the ZIP download.

## Included

- Single/couple projections with Canadian tax and pension estimates, registered/non-registered/corporate accounts, property and debt.
- Withdrawal-order comparisons for lifetime tax, ending net worth and sustainable spending, connected to the annual withdrawal strategy finder.
- Rental sale-year comparisons, keep-versus-sell scenarios, future CCA choices, recapture and terminal loss estimates.
- Earlier retirement searches that can consider selling rentals.
- Current → proposed tax, wealth and benefit changes with signs and red/green indicators.
- Scenario comparisons, pension estimates, optional estate/survivor settings, Monte Carlo checks, JSON transfer/backups and CSV exports.
- Offline browser storage, shared server storage with live updates, optional HTTP authentication, and responsive light/dark layouts.

## Calculation and reliability fixes

Preserves the current annual withdrawal schedule as the optimization baseline; correctly charges opening mortgage debt and cash deficits on property sales; honours zero-interest loan payments; avoids sale-year prepayments and new investment borrowing; recognizes terminal rental losses; and treats unfunded pre-retirement contributions as failed market/spending paths. Workspace edits are preserved during external saved-plan updates, and configuration/scenario handling is more consistent between server and offline modes.

## Verification and limitations

54 calculation tests pass. Browser checks cover real-server and offline operation, comparisons, applying/saving, pensions, synchronization, cancellation, import/export, themes and mobile layouts.

Results are projections under documented assumptions, not guaranteed outcomes or tax-return calculations. Tax thresholds use an indexed 2025 base. The joint retirement search tests multiple rentals in a common sale year rather than all staggered combinations. See the README and calculation notes before making financial decisions.

## Existing users

Export your plan before updating. Keep the server's data volume/appdata directory. For standalone updates, extract the whole new ZIP; import your JSON if moving to a new folder or browser. Review settings and rerun comparisons after updating because corrected calculations may change earlier results.
