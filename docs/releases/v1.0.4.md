# Retirement Calculator 1.0.4

Plan property decisions together and compare their effect on retirement spending before saving any changes.

## Changes since 1.0.3

- **Multi-property rental sale optimization.** Select several rentals to search their sale years jointly. Small searches evaluate the full grid; larger searches use a coarse-to-fine joint grid and coordinate descent, including mixed future-CCA choices. A total 400-option default budget prevents unbounded searches. Progress, cancellation and search-limit reporting remain available. Sampled searches can miss a better combination.
- **New Plan > Properties page.** `plan-properties.html` contains rental comparisons and the debt-versus-investing comparison. Property setup remains under Configuration > Properties. Apply changes the planning workspace; Save plan persists it. Unsaved proposals survive incoming saved-plan updates.
- **Comparable results against keeping rentals.** Both the proposed and keeping alternatives are evaluated at their own maximum sustainable spending, with the same lifespan/estate assumptions and the withdrawal schedule that would actually apply. Unselected properties retain their existing dates. Tax, wealth and income-tested benefit figures identify their units and scope.
- **Simpler property setup.** Rental-only fields disappear for principal residences and HELOCs; HELOCs hide sale/value fields. Added properties receive normalized defaults, property edits preserve category-based spending plans, entered values survive type toggles, and explicit property types take precedence over names containing "HELOC".
- **Review corrections.** Fixed script order and global-variable conflicts that prevented the new page from loading. Joint sale breakdowns identify properties by index, including duplicate names, and show a household sale-tax estimate only once per sale year.
- **Server startup test flake.** Readiness checks now use a 30-second deadline with bounded health requests and early failure diagnostics, accommodating slower CI runners instead of assuming startup within five seconds.

No tax-law change or saved-plan format migration is required from 1.0.3. Spending estimates remain dependent on entered assumptions and the existing $40,000/month search ceiling. No minimum inheritance is reserved.

## Install or upgrade

- **GitHub Pages:** refresh the [calculator](https://asmegin.github.io/Retirement-Calculator/) and open Plan > Properties.
- **Docker/Unraid:** update the image to `ghcr.io/asmegin/retirement-calculator:1.0.4`, retain the existing `/app/data` mapping and host port, and recreate the container. Keep the data and backups directories writable by the configured container user.
- **Compose:** set `APP_VERSION=1.0.4`, then run `docker compose pull` and `docker compose up -d --no-build`.
- **Standalone:** verify `retirement-calculator-standalone.zip` against `SHA256SUMS.txt`, extract all files, and open `index.html` in Edge or Chrome. Export your plan before moving to a different folder.

Export your plan and back up appdata before upgrading. See the [installation guide](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.4/README.md) and [comparison assumptions](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.4/docs/withdrawal-and-rental-comparisons.md).
