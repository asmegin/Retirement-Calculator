# Retirement Calculator 1.0.5

Plan backup, demo and privacy controls now live in App Config. Rental comparison errors identify the fields to correct and link to their configuration page.

## Changes since 1.0.4

- **App Config → Plan file and display:** Export Plan, optional password encryption, Import Plan, Load Demo Profile and Hide figures / Show figures appear here instead of every page header. Storage status, the active-demo badge and Start My Own Plan remain available across pages. Privacy still applies throughout the app and survives reloads.
- **Reliable file controls:** saved-plan updates preserve the encryption checkbox and pending file controls; successful imports keep their visible confirmation. The controls wrap at 320px. Save pending edits before navigating to App Config to export them; exports do not capture unsaved edits on another page. Server-disconnection guidance now tells you to keep the editing page open and reconnect before saving.
- **Actionable rental errors:** invalid ACB, building cost, remaining UCC and past sale years name the rental, field labels and entered amounts or years. Messages retain cents, explain the calculator's input requirements, and provide an Open Properties link to Configuration → Properties, where the fields are under Advanced options. Worker and synchronous errors use the same presentation. The link opens the page rather than a specific property.
- **Readable debt charts:** the debt payoff marker toggle sits above the chart instead of over its legend. Payoff labels stay within the plot, including long property names on narrow screens.

Calculation rules and saved-plan formats are unchanged from 1.0.4. No data migration is required.

## Install or upgrade

- **GitHub Pages:** refresh the [calculator](https://asmegin.github.io/Retirement-Calculator/) and open App Config for plan files, demos and privacy.
- **Docker/Unraid:** update to `ghcr.io/asmegin/retirement-calculator:1.0.5`, retain the existing `/app/data` mapping and host port, and recreate the container. Keep the data and backups directories writable by the configured container user.
- **Compose:** set `APP_VERSION=1.0.5`, then run `docker compose pull` and `docker compose up -d --no-build`.
- **Standalone:** verify `retirement-calculator-standalone.zip` against `SHA256SUMS.txt`, extract all files, and open `index.html` in Edge or Chrome. Export your plan before moving to another folder.

Back up appdata and export your saved plan before upgrading. See the [installation guide](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.5/README.md) and [comparison assumptions](https://github.com/asmegin/Retirement-Calculator/blob/v1.0.5/docs/withdrawal-and-rental-comparisons.md).
